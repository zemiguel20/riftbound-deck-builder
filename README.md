# Riftbound-Archidekt

Deckbuilder for Riftbound, inspired in Riftmana and Archidekt

Take Riftmana deckbuilder as base, but able to create and attach custom tags to cards and organize them like Archidekt. Probably have a tab "Tag Editor" to create and attach customs tags Stats. show distribution of tags, and add a draw calculator as well.
